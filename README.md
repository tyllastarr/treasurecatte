# TreasureCatte
## Treasure Casket Solver for *Final Fantasy XI*
TreasureCatte is a personal project of mine.  While there have been solvers in the past, all the ones I've seen either run on non-secure HTTP or have other irritating bugs.  Thus, I decided to make my own.

### Functionalities
* Supports treasure caskets with anywhere from 1 to 6 attempts.
* Includes functionality for one digit being odd, even, one of a sequence of three numbers.
* Includes functionality for the answer being between two numbers.
* Includes functionality for one of the two digits being a specific number.
* Shows all current clues and possible numbers, with the median highlighted in yellow.
* Shows the percentage chance that you will open the chest given how many possible numbers there are and how many clues are remaining.
